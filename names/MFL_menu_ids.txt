# Frontend menu item list opcodes and action ids (dwords as signed ints appear in the decompile, e.g. 0xFF040000 = -0xFC0000).
# Opcodes (see g_menu_page_item_lists / g_menu_page_NN_*):
0xFF000000  title            arg: text id of the page title
0xFF020000  x                arg: x position
0xFF030000  y                arg: y position
0xFF040000  text item        arg: text id (-1 = no text, e.g. generated entry)
0xFF050000  value item       arg: option value shown with the item
0xFF060000  end entry
0xFF070000  end of list
0xFF080000  item count/mode  arg: count of entries
0xFF090000..0xFF120000  footer buttons (back/select/pause hints)
0xFF140000  action           arg: action id (below)
